# Badge Farmer

[English version](README.md)

Форк **[FrostyDeFreeze/twitch-badge-farmer](https://github.com/FrostyDeFreeze/twitch-badge-farmer)**
для сбора **бейджей каналов и Twitch Drops за просмотр трансляций**.

Исходный проект собирает глобальные значки Twitch. Этот форк добавляет поиск наград
у ваших фолловов и выбирает, какой канал смотреть, учитывая остаток
просмотра, дедлайны и историю эфиров. Нужную награду можно закрепить в приоритете,
чтобы уделять ей максимум доступного времени.

## Что добавлено в форке

- **Поиск наград каналов.** Проверка активных фолловов, отбор бесплатных доступных
  наград и объединение дублей из двух API Twitch.
- **Планирование по дедлайнам.** Порядок просмотра пересчитывается по оставшимся
  минутам, сроку награды, возрасту текущего эфира и прогнозу будущего эфирного времени.
  В плане видны конфликтующие сроки и награды, которые можно не успеть завершить.
- **Оценка длительности стримов.** Публичная статистика
  [Lurkology](https://lurkology.com), кеш и явно обозначенная запасная оценка,
  если данных нет. Прогноз не выдаётся за объявленное стримером расписание.
- **Закреплённый приоритет.** Выбранная награда удерживает слот, пока её канал в эфире
  и условия выполнены. Приоритет меняется и снимается командой.
- **До двух потоков.** Раздельные сессии для разных кампаний. Параллельный зачёт
  проверяется по счётчикам Twitch; при остановке прогресса приоритета второй поток
  временно отключается.
- **Понятные списки и прогресс.** Все фолловы, доступные награды, просмотренные и
  необходимые минуты, даты открытия/закрытия, текущий план. Есть JSON.
- **Уведомления по желанию.** Редактируемая Telegram-карточка с сохранением ID,
  события Discord и универсальный HTTPS webhook. Без настройки ничего не отправляется.
- **Сохранение состояния.** Известные офлайн-награды, кеш статистики и прогресс
  сохраняются между запусками. Получение подтверждает Twitch,
  а не локальный таймер.

## Установка

Скачайте архив со страницы **[релизов этого форка](https://github.com/w11hxhx/twitch-badge-farmer/releases)**:

| Платформа           | Архив                             |
| ------------------- | --------------------------------- |
| Windows x64         | `badge-farmer-windows-x64.zip`    |
| Linux x64           | `badge-farmer-linux-x64.tar.gz`   |
| macOS Apple Silicon | `badge-farmer-macos-arm64.tar.gz` |
| macOS Intel         | `badge-farmer-macos-x64.tar.gz`   |

Распакуйте и создайте конфигурацию:

```sh
./badge-farmer --gen-token
```

На Windows используется `badge-farmer.exe`. Завершите авторизацию Twitch в браузере.
Существующий действующий config можно использовать повторно. Храните `config.json`
приватно.

Добавьте в созданную конфигурацию:

```json
{
	"followDrops": true,
	"scheduler": {
		"maxConcurrentStreams": 2,
		"historyEnabled": true
	}
}
```

Запуск: `./badge-farmer`. Для одного потока установите `maxConcurrentStreams: 1`.

## Команды

```sh
./badge-farmer --channels
./badge-farmer --eligible-channels
./badge-farmer --plan
./badge-farmer --plan --json
./badge-farmer --set-priority "Название награды"
./badge-farmer --set-priority none
./badge-farmer --version
```

Все команды принимают `--config /путь/account.json`. `--channels` включает офлайн-
фолловы. Списки и план не запускают просмотр, не забирают награды и не отправляют
уведомления. Сервис перечитывает сохранённый приоритет при следующем сканировании.
Даты в списках показываются в UTC.

## Уведомления

Уведомления включаются по желанию. Добавьте в конфигурацию только нужные секции:

```json
{
	"notifications": {
		"telegram": { "token": "123456:BOT_TOKEN", "chatId": "123456", "controls": true },
		"discord": { "webhook": "https://discord.com/api/webhooks/123456/WEBHOOK_TOKEN" },
		"webhook": { "url": "https://example.com/private-hook" }
	}
}
```

Telegram обновляет сохранённое сообщение прогресса и восстанавливает его ID после
перезапуска. Discord и HTTPS webhook получают события наград. Проверка настроенных
адресатов:

```sh
./badge-farmer --test-notifications
```

### Управление через Telegram

Включите `notifications.telegram.controls: true` и укажите личный чат с ботом.
Под сообщением прогресса появятся кнопки добавления/удаления каналов и выбора
приоритетного бейджа или канала. Кнопка «Бейджи» открывает доступные варианты.
Также доступны команды:

```text
/add pwgood
/remove логин_канала
/priority_badge PepeLand 11 START
/priority_channel pwgood
/channels
/menu
/cancel
```

Значение `none` снимает соответствующий приоритет. Удалённый канал исключается
из автоматического поиска по фолловам; `/add` возвращает его или добавляет канал,
которого нет среди фолловов. Приоритет бейджа выше приоритета канала.
Настройки сохраняются после перезапуска. Команды принимает только владелец
указанного личного чата. Один токен бота должен обслуживать один получатель
обновлений: другой polling-процесс или webhook конфликтует с управлением.

## Как это работает

1. Проверяет фолловы и находит доступные бесплатные награды за просмотр.
2. Читает прогресс Twitch и объединяет дубли наград.
3. Оценивает оставшееся эфирное время по статистике Lurkology.
4. Удерживает выбранную награду в приоритете, остальные выбирает по дедлайнам.
5. Проверяет прогресс каждого потока, переключает зависшие сессии и подтверждает получение через Twitch.

План пересчитывается при изменении эфиров и прогресса. Статистика Lurkology
кешируется; если данных нет, используется явно обозначенная запасная оценка.
Источник и риск видны в `--plan`.

```sh
bun install --frozen-lockfile

```

Нужен Bun 1.4.3 или новее. Результат: `dist/badge-farmer` (на Windows — `.exe`).

## Возможности и ограничения

Режим фолловов собирает только креаторские бейджи каналов из одноэтапных WATCH
reward groups. Игровые предметы, монеты, эмоции и остальные Drops пропускаются. `followDrops: false` включает исходный режим
глобальных значков по каталогу, включая его поддержку многодневных заданий.

Гарантировать все дедлайны нельзя: канал может не выйти в эфир, закончить раньше,
а Twitch — не засчитать параллельный просмотр. Два открытых потока не означают
два зачтённых. План показывает риски и предполагает один рабочий слот, пока не
подтверждён прогресс обоих. Запускайте один фармер на аккаунт: другие просмотры и
майнеры этого аккаунта могут влиять на зачёт.

Программа использует внутренние, официально не поддерживаемые API Twitch,
которые могут меняться. Покупок, платных подписок и трат Bits нет.
